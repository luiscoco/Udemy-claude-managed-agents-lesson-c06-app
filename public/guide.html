How to run this application

1Install Node.js and open the application folder

Use Node.js 24 or later. From the repository root, install the locked dependencies.

node --version
npm ci

2Create your local .env file

Use your own Anthropic API key and an existing agent ID and environment ID. Copy the example and edit the new file in your editor. The real .env is ignored by Git.

Copy-Item .env.example .env
notepad .env

3Prepare resources or choose the local path

For the optional live path, set your API key, then run npm run setup if you do not already have resource IDs. The script creates the environment before a text-only agent, saves each ID immediately, and reuses IDs already configured. It uses CLAUDE_MODEL or the source default; choose a model available to your account. An uncertain network failure may have created a resource: inspect your account before retrying. Fixtures work without credentials. Set LIVE_ENABLED=true only when you intend to select the live provider.

4Start the application

Run the command below and wait for the printed server URL. Open http://127.0.0.1:3006. The terminal stays open while the server is running. If PORT differs, use that value instead.

npm start

5Run and inspect the evidence

Open the lab, read the stated resource operation, and press the main Run button once. Inspect the returned IDs, configuration or events. Each live run can create a remote resource.

6Verify and stop

Run the source checks below in a second terminal. Stop the web server with Ctrl+C. Local journal records are not production workflow state. Closing a browser tab does not confirm remote cancellation.

npm test

Create and understand .env

Copy the example rather than renaming it. Put your own values in .env; leave .env.example safe for sharing. Restart the server after changing configuration. PORT controls the local URL. An empty optional model value uses the source default.

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MANAGED_AGENT_ID=your_agent_id
CLAUDE_MANAGED_ENVIRONMENT_ID=your_environment_id
LIVE_ENABLED=false
PORT=3006
